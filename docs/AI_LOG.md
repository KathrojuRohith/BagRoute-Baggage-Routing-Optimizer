## Review checklist to apply to any AI-generated change
- Is the MCT comparison `>=` (boundary) and in the right unit?
- Does any worker mutate shared state? (None should.)
- Does every path through `assign()` record the bag as assigned *or* unassigned?
- Does a new test fail if the code is broken (mutation check: flip `>=` to `>` in `graph.py`)?
